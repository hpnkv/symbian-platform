# Getting started

The host tools use Python, CMake, Ninja, Clang/LLD and GTest. The first
object-format probe needs no firmware or target SDK. Emulator runs require
firmware supplied separately.

## Install the host tools

```sh
uv sync
uv run symbian doctor
uv run symbian toolchain probe
```

`doctor` reports available compilers and tools. The probe compiles an ARM
object twice and checks the generated bytes and metadata. Its output stays
under ignored `.symbian/` build state.
