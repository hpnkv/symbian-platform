# C++ reference

The [generated C++ API reference](cpp/index.html) covers public native
headers and implementation. Doxygen rebuilds it from the checked-out C++
source whenever the documentation site is built.

Start with [C++ usage](capabilities/cpp.md) and the
[capability map](capabilities/index.md) to understand runtime support and
verification limits. The generated reference includes some internal native
libraries; its symbol inventory alone is not a phone compatibility claim.
