# Condition Display

The app fills the entire display for four seconds per color, repeating red,
green, blue, yellow, cyan, magenta, white and black. The sequence pauses while
the app is in the background. While foreground, the app keeps the display from
dimming. Close it through the task switcher or Escape.

All display and timing calls use the SDK API. On the Nokia 808, install the
signed `condition_display.sis` from the phone's `Installs` folder.
